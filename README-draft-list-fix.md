# 관리자 초안 목록 최종 수정

- `/admin/post-list?status=draft`가 공개용 `/api/posts`를 재사용하지 않고 관리자 전용 `/api/admin/post-list`를 호출합니다.
- 카운트와 목록은 동일한 상태 정규화 SQL을 사용합니다.
- `draft`, `초안`, `임시저장`, 줄바꿈/탭/전각 공백이 섞인 상태값을 모두 `draft`로 처리합니다.
- 카운트가 존재하지만 첫 목록 조회가 비어 있으면 최소 컬럼 조회로 자동 재확인합니다.
- 응답은 `private, no-store`로 캐시되지 않습니다.
- 대시보드와 기존 `/api/posts`의 상태 정규화도 같은 기준으로 맞췄습니다.
