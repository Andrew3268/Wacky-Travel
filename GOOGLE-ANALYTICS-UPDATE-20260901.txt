Bestayable Google Analytics 적용

측정 ID: G-JJGZWKW70H

적용 범위
- 공개 정적 HTML 페이지
- 목적별 자동 생성 페이지
- 동적 /post/* 페이지
- 동적 게시글 404 페이지

제외 범위
- /admin/*
- /add.html
- /edit.html
- 네이버 소유 확인 HTML
- 게시글 draft preview

구현 방식
- lib/analytics/google-tag.js에 Google tag 코드를 단일 관리
- tools/normalize-static-seo-urls.mjs가 공개 정적 페이지에 중복 없이 삽입
- src/purpose-pages/render-purpose-page.mjs가 재생성 페이지에도 기본 삽입
- functions/post/[slug].js가 동적 게시글에 삽입

성능 최적화 업데이트 (2026-09-09)
- dataLayer와 gtag() 큐는 HTML 파싱 시 즉시 준비
- gtag('js') / gtag('config') 명령도 즉시 큐에 저장하여 GA4 설정을 보존
- 외부 gtag.js 다운로드만 1,000ms 이후 브라우저 idle 시점으로 지연
- 1,500ms 하드 타임아웃으로 과도한 지연 방지
- 1.5초 전에 pointer/touch/keyboard 상호작용이 있으면 즉시 로드하여 이벤트 누락 가능성 완화
- 페이지가 hidden/pagehide 상태가 되면 즉시 로드를 시도하여 빠른 이탈 측정 안전장치 제공
- 기존 즉시 로딩형 Google tag가 남은 정적 HTML은 seo:normalize 과정에서 자동 교체
- /admin/*, /add.html, /edit.html, 네이버 소유 확인 HTML, draft preview 제외 정책은 유지
